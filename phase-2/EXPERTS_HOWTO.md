# Инструкция экспертам: фаза 2

Для: Попова Полина (эксперт 2), Пауликайте Елона (эксперт 3).
Задачи YouGile: Ф2-04 (оценка трудоемкости) и Ф2-05 (предпочтения). Время: около 45 минут.

Оценивайте самостоятельно, не глядя на листы других экспертов.

## 0. Перед началом

1. `git pull`
2. Прочитать `phase-2/phase3_tasks.md`: 13 задач фазы 3 с описанием результата и зависимостями.

## 1. Книга `phase-2/Оценки_задач_фазы3.xlsx`, свой лист `Эксперт2` или `Эксперт3`

Для каждой из 13 задач заполнить желтые ячейки:

| Столбец | Что вписать |
|---------|-------------|
| C "Оценка, ч (тур 1)" | сколько часов чистой работы займет задача у ОДНОГО человека (от 0,5 до 40, можно 1,5 и т.п.) |
| E "Предпочтение 1-5" | насколько вы хотите делать эту задачу: 1 - совсем не хочу, 3 - все равно, 5 - очень хочу |

Столбец D (тур 2) пока не трогать.

Подсказка по часам: оценивайте задачу как "сделать хорошо для отчета", а не "набросать".
Митинги, покер планирования и оценка факторов UCP в этот список не входят - они общие.

Про предпочтения: это не голосование за то, кто умнее, а вход для модели распределения.
Модель старается отдать каждому задачи с высоким предпочтением, но держит нагрузку
примерно равной. Поэтому честные оценки выгоднее всем.

## 2. Тур 2 (после того как все заполнят)

На листе `Сводка` у задач с большим разбросом (max/min > 1,5) появится статус "обсудить".
На коротком созвоне (Ф2-06) каждый объясняет свою оценку, после чего ТОЛЬКО по этим задачам
каждый вписывает новую оценку в столбец D. Итог по задаче - медиана трех оценок.

## 3. Сохранить и отправить

Вносим по очереди (xlsx не сливается): сначала Полина, потом Елона после `git pull`.

```bash
git pull
git add phase-2/Оценки_задач_фазы3.xlsx
git commit -m "Фаза 2: оценки эксперта N"
git push
```
