# Фаза 2. Декомпозиция работ фазы 3

Проект: **"Онлайн-запись к мастеру"** (выбран в фазе 1).
Фаза 3 по плану: 03.11-16.11.2026.

Работы фазы 3 разделены на два вида:

- **индивидуальные задачи** (Ф3-01...Ф3-13) - их делает один человек; именно они
  распределяются задачей о назначениях (`assign_phase3.py`);
- **общие активности** (Ф3-14...Ф3-17) - в них участвуют все трое, в распределение не
  входят, их часы добавляются к нагрузке каждого как постоянная часть.
