## Метод оценки трудоемкости

Широкополосный Дельфи: каждый независимо оценивает часы (тур 1); задачи с разбросом
max/min > 1,5 обсуждаются и переоцениваются (тур 2); согласованная трудоемкость - медиана.

## Постановка задачи распределения

- x_ij = 1, если задача i назначена участнику j;
- каждая задача ровно у одного исполнителя;
- нагрузка каждого (свои задачи + 4,5 ч общих активностей) отклоняется от средней не больше
  чем на 15%;
- у каждого не меньше 3 задач;
- целевая функция: максимум суммы p_ij * h_i (предпочтение, взвешенное трудоемкостью).

Для сравнения считаются модель B (минимум максимальной нагрузки, без предпочтений) и модель C
(максимум предпочтений без ограничения баланса).
