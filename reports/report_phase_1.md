## 5. Нечеткий коллективный TOPSIS

Методика:

1. Три оценки экспертов по каждой ячейке упорядочиваются и образуют треугольное нечеткое число
   (l; m; u) = (MIN; MEDIAN; MAX) - пессимистичная, ожидаемая и оптимистичная оценки.
2. Нечеткие веса критериев: w = (l/9; m/9; u/9).
3. Нормализация: для критериев-польз r = (l/u*; m/u*; u/u*), u* - максимум u по критерию; для
   критериев-затрат r = (l-/u; l-/m; l-/l), l- - минимум l по критерию.
4. Взвешивание: v = r * w покомпонентно.
5. Идеальные решения: A+ = max u по критерию, A- = min l по критерию.
6. Расстояние между ТНЧ: d = sqrt(((l1-l2)^2 + (m1-m2)^2 + (u1-u2)^2) / 3); d+ и d- - суммы по
   критериям.
7. Коэффициент близости CC = d- / (d+ + d-), ранжирование по убыванию.

Нечеткие веса критериев (l; m; u) / 9:

## 6. Четкий коллективный МАИ

Методика:

1. Каждый эксперт заполняет матрицы парных сравнений: критериев между собой и альтернатив по
   каждому критерию (1 + 5 матриц).
2. Индивидуальная согласованность: CR = CI / RI, CI = (lambda max - n) / (n - 1); RI = 0.90 для
   n = 4, 1.12 для n = 5. CR > 0.1 - эксперт пересматривает суждения.
3. Коллективная матрица: поэлементное среднее геометрическое суждений экспертов (AIJ), сохраняет
   обратную симметричность.
4. Локальные веса: нормированное среднее геометрическое строк; проверка CR коллективных матриц.
5. Глобальный приоритет альтернативы: сумма произведений локальных весов на веса критериев.

Коллективные матрицы:

## 7. Сравнение результатов и выводы

| Альтернатива | TOPSIS: CC / ранг | МАИ: приоритет / ранг |
|--------------|-------------------|-----------------------|
| Запись | 0,621 / 1 | 0,407 / 1 |
| Бронь | 0,494 / 2 | 0,267 / 2 |
| Бюджет | 0,388 / 3 | 0,157 / 4 |
| Привычки | 0,358 / 4 | 0,168 / 3 |

1. Оба метода ставят на первое место концепцию "Онлайн-запись к мастеру" с заметным отрывом:
   CC 0,621 против 0,494 у второго места, в МАИ 0,407 против 0,267. Лидерство обеспечено
   критериями K3 (по нему все три эксперта дали Записи 9 из 9), K1 и K4.
2. Второе место в обоих методах у "Бронирования переговорных".
3. Расхождение только в паре Бюджет / Привычки, и разница между ними мала в обоих методах
   (0,030 в TOPSIS, 0,011 в МАИ). В TOPSIS Привычки отстают по расстоянию до идеала сразу по
   K3, K4 и K5, и лидерство по простоте этого не компенсирует. В МАИ попарные суждения по K2
   дали Привычкам большой локальный вес, а сам K2 получил высокий вес 0,235 - этого хватило,
   чтобы обойти Бюджет.
4. Веса критериев в методах согласуются: в обоих наиболее важен K3, наименее - K4. В TOPSIS веса
   ближе друг к другу (шкала 1-9 сжимает различия), в МАИ попарные сравнения их растягивают.
5. Разброс экспертных оценок небольшой: ширина ТНЧ (u - l) не больше 1 балла у 22 из 25 ячеек,
   максимум 3 балла (Запись по K4: 5-8). Поэтому нечеткий TOPSIS дает результат, близкий к
   четкому.

**Решение:** для дальнейшей работы (фазы 2-5) выбрана концепция A3 "Онлайн-запись к мастеру":
4 актора (клиент, мастер, администратор, SMS-шлюз) и 13 черновых use case с альтернативными
сценариями дают содержательную основу для оценки в COSMIC FP и UCP.

Расчеты Excel сверены с независимым пересчетом `phase-1/calc_phase1.py` - результат сверки: совпадение по всем CC, весам, CR и приоритетам.
