# Фаза 1. Выбор концепции проекта

| Файл | Содержание |
|------|------------|
| `concepts_and_criteria.md` | 4 концепции, 5 критериев, шкалы, требования к LLM |
| `TOPSIS.xlsx` | нечеткий коллективный TOPSIS: `Справочник` -> `Ввод` -> `Расчет` |
| `МАИ.xlsx` | четкий коллективный МАИ: `Справочник` -> `Эксперт1..3` -> `Коллективный` |
| `calc_phase1.py` | независимый пересчет обоих методов на Python для сверки с Excel |

## Как заполнять

1. Названия концепций и критериев после утверждения правятся только на листе `Справочник`
   (в обеих книгах одинаково).
2. `TOPSIS.xlsx`, лист `Ввод`: каждый эксперт заполняет свой блок - важность 5 критериев и
   оценки 4 альтернатив по шкале 1-9 (целые числа).
3. `МАИ.xlsx`, свой лист `ЭкспертN`: желтые ячейки выше диагонали, шкала Саати. Обратные
   значения вводятся формулой (`=1/3`). Если в строке `CR` написано "пересмотреть" -
   скорректировать суждения этой матрицы.
4. Результат: `TOPSIS.xlsx` -> `Расчет`, раздел 6 (CC и ранг); `МАИ.xlsx` -> `Коллективный`,
   блок "Синтез".
5. Сверка:

```bash
pip install openpyxl numpy
python calc_phase1.py
```

Числа в выводе скрипта должны совпасть с листами `Расчет` и `Коллективный`.

Пока экспертные оценки не внесены, расчетные ячейки показывают ошибки (`#DIV/0!`, `#NUM!`) -
это нормально.
