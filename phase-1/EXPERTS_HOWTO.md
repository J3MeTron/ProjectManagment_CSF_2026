# Инструкция экспертам: что внести в фазе 1

Для: Попова Полина (эксперт 2), Пауликайте Елона (эксперт 3).
Срок: до 18.10 (задачи YouGile PRO-7 и PRO-8).
Время: около 1,5 ч на человека.

Оценивайте самостоятельно и не смотрите блоки других экспертов: три оценки должны быть
независимыми, иначе нечеткий TOPSIS теряет смысл.

## 0. Перед началом

1. Прочитать `phase-1/concepts_and_criteria.md`: 4 концепции (Бронь, Бюджет, Запись, Привычки)
   и 5 критериев (K1-K5) с пояснениями.
2. Получить свежую версию репозитория:

```bash
git clone https://github.com/J3MeTron/ProjectManagment_CSF_2026.git
```

Если репозиторий уже склонирован:

```bash
git pull
```

## 1. TOPSIS.xlsx, лист `Ввод` (25 чисел)

Заполнить только желтые ячейки своего блока. Целые числа от 1 до 9.

| Эксперт | Важность критериев | Оценки концепций |
|---------|--------------------|------------------|
| Эксперт 2 (Полина) | строка 18, B-F | строки 21-24, B-F |
| Эксперт 3 (Елона) | строка 31, B-F | строки 34-37, B-F |

- Важность критерия: 1 - почти не важен, 9 - критически важен.
- Оценка концепции по критерию: 1 - очень плохо, 9 - отлично. Строки - концепции, столбцы -
  критерии.

## 2. МАИ.xlsx, свой лист `Эксперт2` или `Эксперт3` (40 сравнений)

На листе 6 матриц: критерии между собой (5x5, 10 ячеек) и концепции по каждому из 5 критериев
(4x4, по 6 ячеек). Заполнять только желтые ячейки выше диагонали, нижняя половина считается
сама.

Шкала Саати - насколько элемент СТРОКИ лучше (важнее) элемента СТОЛБЦА:

| Значение | Смысл |
|----------|-------|
| 1 | равноценны |
| 3 | умеренно лучше |
| 5 | существенно лучше |
| 7 | очень сильно лучше |
| 9 | абсолютно лучше |
| 2, 4, 6, 8 | промежуточные |

Если элемент строки ХУЖЕ элемента столбца - вводить обратное значение формулой: `=1/3`,
`=1/5` и т.д. (просто `1/3` Excel превратит в дату).

Проверка: под каждой матрицей в столбце G появляется статус. Должно быть "согласовано"
(CR не больше 0,1). Если написано "CR > 0,1: пересмотреть" - суждения противоречат друг другу
(например, A лучше B, B лучше C, но C лучше A), поправьте эту матрицу.

Совет: чтобы МАИ не противоречил вашим оценкам в TOPSIS, сравнивайте, глядя на свои числа из
листа `Ввод`. Например, оценки 8 и 6 дают сравнение около 2-3 в пользу первой.

## 3. Сохранить и отправить

Файлы xlsx git не умеет сливать, поэтому вносим ПО ОЧЕРЕДИ: сначала Полина, затем Елона
(Елона делает `git pull` уже после пуша Полины).

```bash
git pull
git add phase-1/TOPSIS.xlsx phase-1/МАИ.xlsx
git commit -m "Фаза 1: оценки эксперта N"
git push
```

Перед `git add` закрыть файлы в Excel.
